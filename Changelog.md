## [6.2] — Исправление багов

### Критические
- **Определение победителя.** Раньше проверка победы находилась в недостижимой ветке, поэтому последний выживший продолжал играть сам с собой до смерти. Теперь победитель определяется корректно, как только остаётся один игрок.
- **Состояние игры вынесено в лобби.** `GameManager` больше не хранит игру глобально — теперь на сервере может одновременно идти несколько независимых игр в разных лобби.
- **Флаг `gameStarted` сбрасывается после игры.** Раньше лобби навсегда «залипало» после окончания партии (в него нельзя было зайти и начать новую игру).
- **Зависание сервера устранено.** При `bulletCount > chamberSize` был бесконечный цикл, при `chamberSize = 0` — исключение. Значения теперь валидируются и ограничиваются.

### Логика
- **Для старта игры теперь требуется минимум 2 игрока (было `< 1`)**.
- **Все игровые и командные сообщения идут через ` LocalizationManager`, и `/roulette lang ru|en`** меняет язык для каждого игрока индивидуально.
- **Добавлена обработка выхода игрока (`PlayerQuitEvent`)**: отключившийся игрок больше не блокирует игру и не оставляет «висящих» ссылок.
- **Исправлен порядок хода при выходе игрока из середины списка**.
- **Счётчик раундов теперь увеличивается и отображается в сообщении о ходе**.
- **Исправлен off-by-one**: первая камора (индекс 0) больше не пропускается.

### Прочее / чистка
- **Добавлена команда `/roulette reload`** (право `russianroulette.reload`) — перезагрузка конфига и локалей.
- **Язык стал общим для всего сервера (был персональным у каждого игрока)**. Раньше `/roulette lang` менял язык только у того, кто ввёл команду, — теперь меняется для всех, выбор сохраняется в `config.yml` (`language: ru_RU|en_US`) и переживает перезапуск.
- **Смена языка (`/roulette lang`) вынесена под отдельное право `russianroulette.lang`** (по умолчанию `op`) — язык меняет администратор.
- **`plugin.yml`: убраны несуществующие подкоманды/права (`reloadplugin`)**, исправлена строка `usage`.
- **Удалён мёртвый класс `LangCommand`**.
- **`CommandHandler` создаётся один раз** (был продублирован для executor и tab-completer).
- **Пустые лишние лобби автоматически удаляются** (устранён рост числа лобби).
- **Исправлены опечатки в сообщениях** («left»/«loss» без пробела и т.п.).
- **`config.yml` очищен**: остались только игровые настройки, тексты — в `locale/`.
- **Удалён неработавший метод `LocalizationManager.format()`**.
