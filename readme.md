## Мини-игра "русская рулетка"

Плагин переносит знаменитую игру "Русская рулетка" в Minecraft.
Группа людей собирается в лобби и каждый по очереди стреляет в себя, победителем становится последний выживший в группе.

---

## Возможности

- Система лобби.
- Настраиваемое количество камор и патронов.
- Локализация на несколько языков.
- Лидером лобби считается игрок, зашедший первым в лобби.

---

## Команды

> Алиас команды - /rr.

| Команды                | Действия                                          | Права                  |
| ---------------------- | ------------------------------------------------- | ---------------------- |
| */roulette leave*      | Выход из текущей группы                           | russianroulette.use    |
| */roulette join*       | Присоединение к свободной группе                  | russianroulette.use    |
| */roulette start*      | Запуск игры(может только лидер, минимум 2 игрока) | russianroulette.use    |
| */roulette list*       | Список активных лобби                             | russianroulette.use    |
| */roulette lang ru/en* | Переключение языка                                | russianroulette.lang   |
| /roulette reload       | Перезагрузка конфигурации                         | russianroulette.reload |

## Файл config.yml(По умолчанию)

```yml
chamberSize: 6            # Количество камор в барабане (>=1)
bulletCount: 1            # Количество патронов в барабане(ограничивается диапазоном 1...chamberSize)
maxPlayers: 4             # Максимум игроков в лобби
roundDelayTicks: 60       # Задержка между ходами в тиках
```

---

## Локализация
###### Тексты сообщений хранятся отдельными файлами в папке плагина
locale/messages_ru.yml - русский язык
locale/messages_en.yml - английский язык
> Допускаются плейсхолдеры: '%player%', '%round%', '%winner%', '%id%', '%count%', '%max%', '%slots%', '%status%'.
> Цветовые коды через '&'.

## Вопросы/Ответы
##### Это полная версия плагина?
В данный момент весь плагин является полностью бесплатным

##### Как мне собрать плагин из исходных файлов?
Для сборки потребуется Java JDK 21 и Maven.

Выполните команду:
```bash
mvn package
```

После завершения сборки готовый файл .jar будет находиться в папке target/.
##### Как мне добавить свою локализацию?
Добавление локализации происходит путем создания файла в папке src/main/resources/locale/messages_<код>.yml, копировании переменных и регистрации файла в LocalizationManager
